Retrying missing sections must preserve successful results. Summary failure must not erase the transcript. Partial notes are allowed with a persistent partial label.
- Connection: new installations can supply their own OpenAI API key; existing installations retain their Team token. ## Verified baseline and constraints

Swift 6.2.3 / macOS 26 / arm64, macOS minimum 13, SwiftPM with no dependencies. Existing build and merge/naming selftest pass. AppModel currently combines everything; AppDelegate owns accessory menu-bar popover and settings window. Recording uses AVFoundation mic CAF and ScreenCaptureKit system WAV. Existing mic waits for first system buffer and can fail silently. Per-chunk provider errors are swallowed and AppModel then deletes recovery audio. Segment offsets assume fixed chunk duration despite converter overshoot.

The deployed file proxy supports transcription and chat endpoints, 120 requests/person/hour by default, and gpt-4o/gpt-4o-mini summaries. No Realtime route. Keep current proxy and credentials. Avoid a new backend or changing existing secrets.

Model choices: gpt-transcribe for completed dictation and provisional preview. For timed final meeting source turns use gpt-4o-transcribe-diarize with diarized_json + chunking_strategy=auto; online source labels You / System audio, in-person label Microphone. Do not invent participant names or fabricate word/segment timing for text-only outputs. Summary uses the existing allowed gpt-4o model and cites real supplied turn IDs. Include original notes in summary context; edit summaries separately.

Preview is optional provisional text from completed rolling audio windows, not a second authoritative transcript. Initial bounded path mixes one finalized window about every45 seconds, preserving both original tracks. This uses ~80 requests/hour and leaves room for final transcription and retries under the existing proxy cap. Preview failure never stops recording. Short live-word latency via Realtime is deferred; surface only a Preview badge, not internal retry stages. Record this cadence difference in the completion report.

## Architecture and owned contracts

Keep one active capture and one coherent AppModel coordinator. SwiftUI handles library, settings and chip contents; AppKit handles status menu, windows, global events and insertion. Do not add a generic service framework.

Core additions: typed per-source levels/health/errors, safe mic startup independent of system silence, finalized preview windows, provider models/formats, typed chunk outcomes, cached successful chunks, genuine timed segments, structured notes with validated source references, sanitized errors and injectable URLSession transport. Preserve CLI entry points through compatible defaults where practical.

Foundation session records/store live in TranscribeCore, owned by root. Each UUID session has atomic record.json plus raw artifacts in Application Support/Transcribe/Sessions/<id>. SessionRecord includes kind, online/in-person mode, title, date/duration, processing status, delivery outcome, notes, preview, final text/turns, summary status/content/evidence, audio references and missing sections. A startup load converts interrupted capture/processing records to recoverable failures. Existing Markdown is imported read-only through Settings, once per source path; immutable importURL preserves provenance across subsequent exports. New successful meetings still export Markdown to the selected folder. Never delete legacy files or existing unknown artifacts.

AppModel commands: startDictation, finishRecording, cancelDictation, startMeeting, recover/retry(recordID), regenerateNotes(recordID), updateTitle/updateNotes/updateSummary, copyTranscript, pasteLast, export/reveal, selectSidebar/record. Published state: records, selectedRecordID, sidebar selection, active session ID/kind/phase, chip state, elapsed/levels/source health, meeting setup mode/title, searches, permissions and persisted settings. Root owns final exact Swift contract and integration.

Native services: ShortcutService recognizes clean Option press/release pairs and configurable paste-last binding. Intervening keys/modifiers, held Option and shortcut repeats invalidate pairs. Event tap consumes Escape only during dictation; if unavailable, expose the actual missing permission. After saving final text, PasteService resolves the currently focused external editable field and posts a guarded Command–V to that app. No direct AX mutation or subsequent fallback. It verifies insertion where readable, preserving all previous clipboard formats only after confirmed consumption and only while owning the clipboard. Unconfirmed delivery retains the transcript clipboard and contextual history warning; explicit Copy remains available. Manual paste-last uses the same current-caret transaction with serialized requests. Never overwrite a clipboard changed by the user. Floating panel must not activate, become key/main or steal the destination.

UI: native split-pane library with Dictation/Meetings/Dictionary/Settings, functional search/copy/recover actions, permission/token setup only when needed, meeting notes/transcript/summary tabs, inline title and notes editing, source failures and partial states. Dictionary is a small persisted list of transcription hints, not an unrelated feature expansion. Keep labels terse and warnings actionable. Bundle exact Figma icon assets and licensed Urbanist fonts; map semantic colors from docs Circles v2.8.7 export.
